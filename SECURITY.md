# Security policy

## Supported versions

The project is pre-1.0. Security fixes apply to the latest released version only until a broader support policy is published.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Contact the maintainer privately through the security reporting mechanism that will be configured on the public repository before the first release.

Until that mechanism exists, do not deploy this project against production infrastructure.

## Safety scope

- The project is designed for isolated test environments.
- Scenarios must use synthetic credentials and canaries.
- The reference agent is read-only.
- No release currently claims production readiness.
